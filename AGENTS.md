# AGENTS.md

Repo for Frames' official UI: a Tailwind-based CSS design system (pre-defined styles for HTML tags plus custom classes) shipped as a single stylesheet on GitHub Pages.

## Commands

- `npm run dev` — Vite dev server
- `npm run build` — Vite build (no typecheck/lint/tests exist in this repo; this is the verification step)
- `npm run style` — compile `style.css` + `src/styles/*.css` into `public/style.css` via the Tailwind CLI

## Critical: `public/style.css` is generated output that is committed

`public/style.css` is the actual distributed artifact (README references `https://pr4j3sh.github.io/ui/style.css`). It is regenerated by `npm run style`, so after editing styles in `style.css` or `src/styles/`, run `npm run style` and commit the regenerated file alongside your source changes. CI also runs it (`npm ci && npm run style && npm run build`) before deploying to GitHub Pages on push to `master`.

## Architecture

- `style.css` is the stylesheet entry; it `@import`s `src/styles/*.css` in a fixed order: `tailwind`, `tokens`, `root`, `layout`, `typography`, `media`, `forms`, `feedback`, `button`, `misc`. Keep new styles in these files. `tokens.css` defines all color/spacing/font tokens as RGB-triplet CSS variables on `:root` + `.dark`, mapped into the Tailwind theme in `tailwind.config.js` (`rgb(var(--c-x) / <alpha-value>)`).
- Two Vite build inputs: `index.html` (home) and `components/index.html` (docs page showing each component's usage). Both load `main.js`.
- `main.js` injects shared chrome into placeholder IDs: `#navbar` (navbar.js), `#footer` (footer.js), `#theme-toggle` (theme.js), and demo content into `#components` (components.js).
- `src/lib/consts.js` is the single source of truth for `SITE`/`AUTHOR` (title, URLs, repo name); nav links are derived from it.
- `src/assets/icons/index.js` exports inline SVGs (used by the theme toggle).

## Conventions and gotchas

- Dark mode uses Tailwind `darkMode: "selector"` — `dark:` utilities are gated by the `.dark` class on `<html>`, not the default media query. Toggling + persistence (`localStorage` with `prefers-color-scheme` fallback) lives in `src/lib/theme.js`. Keep it class-based; don't switch to media-query dark mode.
- Vite `base` is `"/ui/"`, so absolute URLs in HTML/JS must be prefixed with `/ui/` (e.g. `href="/ui/components/"`, navbar builds `/${SITE.REPO}/`).
- Tailwind `content` only scans `./src/**/*.{html,js,css}`, `./index.html`, and `./style.css`. Utility classes used in `components/index.html` or `public/` are NOT picked up — put shared utilities in `src/styles/*.css` via `@apply`.
- Commit messages are prefixed with `fix:` / `feat:` (e.g. `fix: avatar image`, `feat: added avatar`).
